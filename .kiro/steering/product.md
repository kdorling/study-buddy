# Product Overview

Study Buddy is an AI-powered desktop study companion that helps students understand difficult passages from academic materials. The application provides document viewing for PDF and EPUB files with text selection, annotation, and AI-powered explanations via Google's Gemini API.

## Core Features

- PDF and EPUB document viewing with navigation
- Text selection and annotation with visual indicators
- AI explanations for selected passages using Gemini API
- Conversation history with follow-up questions
- Markdown and LaTeX math rendering in AI responses
- Offline document viewing and annotation management
- Persistent reading position tracking
- Document library with annotation search

## Target Users

Students studying from textbooks, research papers, and academic ebooks who need AI assistance to understand complex material.
